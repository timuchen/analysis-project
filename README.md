# Проектная работа модуля 6. Рефакторинг кода на Rust

Прототип парсера логов: читает файл с логами, разбирает строки и фильтрует их по requestid, ошибкам и операциям со счётом. В рамках работы код переписан на более идиоматичный Rust: убраны лишние clone, Rc/RefCell, unsafe и singleton, а вместо ручных проверок и паники используются tight-типы и enum.

```
cargo test
cargo run example.log
```
